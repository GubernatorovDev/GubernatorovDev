# Python Developer

Разрабатываю backend-сервисы и инструменты автоматизации на Python. Проектирую API, работаю с базами данных и внешними интеграциями, выстраиваю понятную структуру приложения и уделяю внимание надёжности сервиса на всех этапах — от разработки до развёртывания.

## Стек

- Python, Django и FastAPI
- Pydantic, SQLAlchemy и Alembic
- PostgreSQL, Redis и SQL
- REST API, асинхронные задачи и внешние интеграции
- Celery и фоновые задачи
- Docker, Linux и автоматизация развёртывания
- Pytest и тестирование backend-логики
